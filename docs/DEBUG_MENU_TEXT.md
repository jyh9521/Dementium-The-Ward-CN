# 原生调试菜单的简体中文文本层

## 已验证：本作源表与译文分离

- 输入绑定 Steam build21501403 / 原 EXE SHA-256 `26186ceb1142e1c84298aa528627531e3821b8068e4e777e3975403a272c530e`；没有复制《病房2》的地址或数据结构。
- `locales/zh-CN/debug-menu.json` 记录本作 21 张表的 RVA、条目数、原表 SHA，以及每个名称的 source、target、原字符串 RVA、name pointer RVA 与 callback RVA。
- 根表 RVA `0x2EA510`，70 项；20 张子菜单合计 255 项。总计 325 个名称字段、306 个不同标签、2 个布尔状态，共 308 个译文条目。环境参数虽部分指向原生空回调 `0x2EE00`，仍保留并翻译原名称，不新造参数效果。
- 子菜单表：`2E9510/9`、`2E95A0/15`、`2E96A0/29`、`2E9870/5`、`2E98C0/4`、`2E9900/13`、`2E99D0/10`、`2E9A70/15`、`2E9B60/11`、`2E9C10/3`、`2E9C40/19`、`2E9D70/5`、`2E9DC0/21`、`2E9F10/18`、`2EA030/3`、`2EA060/12`、`2EA120/19`、`2EA250/28`、`2EA410/2`、`2EA430/14`。这里 `/` 后为十进制项数，RVA 为十六进制。

## 已验证：指针池与容量

本作 `C62A0`、向上/向下滚动路径把名称复制到 `menu+720+row*40`，值复制到 `menu+A20+row*40`；每字段为 64 bytes。名称上限 63 bytes（不含末尾 NUL）。布尔 callback 的临时目标是 16-byte 栈字段，因此状态单独守 15 bytes。不是把中文原地塞入短 ASCII 字槽，也不修改加载关卡的机器 ID。

`tools/debug_menu_text.py` 返回独立 UTF-8 池和精确修改 runs；调用方把池放入映射的 `.locdbg`。325 个 name pointer 已有 DIR64 重定位记录；只重定向名字，不修改 callback，不增造绝对指针重定位。源表摘要、每个源字面量、原 callback、现有重定位记录都先检查。池与字体字符集均从 locale 文件生成。

`true/false` 的原始字面量 RVA 为 `0x3054F4/0x3054EC`，被游戏其他路径共享，所以不在原地覆盖。仅修改本作 8 个调试 callback 内的 16 条 RIP-relative LEA：`C5D70/C5DB0/C5E00/C5E70/C5EE0/C5F20/C5F60/C5FA0`；译为“开启/关闭”。没有改变这些 callback 的开关逻辑、保存逻辑或全局变量含义。数值、格式控制符和关卡 ID 保持原样。

## 已验证：离线原指令消费

`replay_debug_menu_text` 在 `0x140000000`、`0x180000000` 两基址映射改后 PE：

1. 原 `C62A0` 执行 76 次分页填充，比较 650 个名称副本（两基址各 325）。页面 callback 只返回空值，避免把查询回放冒充游戏状态效果。
2. 单独执行上述 8 个真实 boolean callback 的查询分支，分别输入 false/true；32 次停在原 `snprintf` 边界，捕获选中的“关闭/开启”UTF-8 指针。没有把测试中的 formatter 截获当作真实 libc 或 GPU 执行。
3. 实际改后 `EA700` decoder 对 308 个不同译文逐项解码，再经原生查字/测宽函数比较生成 binfont 的 advance；调用原生文字编译/GPU边界的 fixture 约定与现有 UTF8Replay 一致。
4. 9 项文本单测检查完整表覆盖、重复 ID、标签/状态容量、机器 ID 保留、Unicode边界、源身份漂移、真实表正反向恢复。

本地研究报告是 `build/debug-menu-research/text-replay.json`，不提交游戏二进制、完整源表或字体。最终整包验证报告由上层构建记录；单独文本层的通过不等于完整菜单渲染、真实设备输入或每条作弊命令效果验收。
