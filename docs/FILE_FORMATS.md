# 文件格式清单（本作 build21501403）

第二阶段：binfont字段、页表、双层zlib及分区/重定位现已交叉验证，完整定义见[BINFONT_FORMAT.md](BINFONT_FORMAT.md)。主菜单单字节入口见[TEXT_DECODING.md](TEXT_DECODING.md)。下面媒体未知项仍保留，不套用PNG扩展名。

## 已验证：ZAR1

全部小端，头部32字节 `<8I>`：

| 偏移 | 值 | 解释 |
|---|---|---|
|0x00|ZAR1|签名|
|0x04|668|成员数|
|0x08|0x100000|预加载头部大小|
|0x0c|0|未知，拒绝其他变体|
|0x10|0x20|u32名称相对偏移数组|
|0x14|0xA90|名称池绝对偏移|
|0x18|0x6BA0|TOC绝对偏移|
|0x1c|0|未知，拒绝其他变体|

ASCII NUL结尾名称按原顺序严格升序，无不安全路径。TOC每项 `<QQQ>`：绝对数据偏移、长度、未知值0。载荷均512字节对齐。当前无外层解压步骤，不将未知值叫做压缩flag。

ZAR回写原字节保留，修改成员追加到512对齐尾部，只更新对应TOC；无修改时全包逐字节相同。

## 已验证：~INDEX双索引

u64数量602；每记录 `<IIQ>`：size、flags、name_offset。名称池始于 `8+602*16`，name_offset相对池起点，ASCII `/`前缀NUL结尾。全部flags0。601项关联包内，另有外部LICENSES.TXT。修改成员长度时同步size；名称、flags、顺序保留。未知外部成员/flags或旧大小不匹配拒绝。

## 已验证：内层TAR

`CONTENT.TAR` 包含2555个标准512字节头成员，文件2522、目录33；本包无PAX/链接/长名扩展。Python tarfile验证各头校验和，适配器另检名称、边界和零结束区。

保留原始头、未改载荷与padding；修改成员时写入octal size字段(124..135)，将checksum字段(148..155)暂置空格后求和重写，再按512对齐载荷。后续成员按原顺序移动，尾部原零区保留。无修改完整字节相同。增长后更新ZAR与VFS，不依赖旧TAR绝对偏移。

## 已验证：文本字节结构；运行时编码待确认

- `loc/<locale>/*.tbl`：物理CRLF/LF行，空行占ID行号；按非空行提取。
- `loc/<locale>/{examine,item,open,unlock}.<数字>`：一资源一记录，保留内部换行与颜色等控制字节。
- 不猜测控制码语义；保护1..8等控制字符、`|`、格式标记序列。表格禁止增加换行，文档保存原换行序列；源metadata过期、ID缺失或重复拒绝。
- 源码JSON采用UTF-8；`encoding=latin-1`是调查时0..255字节的无损视图，不是运行时兼容承诺，target保持空。
- 5语言655资源1390记录全部生成本地清单。EN8张表155非空行+123文档=278记录。图片/EXE/未知资源不计入该分母。
