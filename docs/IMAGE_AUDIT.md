## 已验证的容器格式

小端；容器没有标准PNG签名。

| 相对偏移 | 类型 | 已验证结构 |
|---|---|---|
| 0 | u32 | 观察值122；语义未确认，保留原值 |
| 4 | u32 | 观察值32；语义未确认，保留原值 |
| 8 | u32 | 宽度 |
| 12 | u32 | 高度 |
| 16 | u32 | 外层解压后字节数 |
| 20 | u32 | 外层LZ4压缩块长度 |
| 24 | bytes | LZ4 block，不含lz4.frame头或自带长度前缀 |
| 后接 | bytes | `4 - (压缩块长度 % 4)` 个零，即1–4个，不是0–3个 |

外层解压数据：`<u32 RGBA字节数, u32 内层压缩块长度>`，随后为内层LZ4 block及相同1–4字节零填充。内层解压长度严格等于`宽*高*4`。将其按RGBA解释与已解码PNG逐字节一致。

319项两层填充均为零；未发现其他尾部flags。不能据此给头部122/32指定枚举含义。codec将其保存为`header_words`，默认原样保留，可用`expected_header`绑定已确认变体；并非承诺其他header变体也获原生支持。

## 通用codec与验证

- `tools/texture.py` 提供 `Texture(data, expected_sha256=..., expected_header=...)`、`describe()`、`rebuild(rgba)`和`Texture.encode(...)`。
- 头部、压缩块、尾部、尺寸、RGBA长度均有边界验证；默认RGBA上限64MiB、单边16384；已知源SHA不匹配即拒绝修改。
- 不变写入返回原始编码字节；修改仅允许同尺寸RGBA，重新编码后再次解码逐像素验证；保留两个不透明头字段。
- 修改构建为确定性双层LZ4输出；不复制任何游戏专用名字、路径、哈希或程序偏移进codec。
- Python依赖：`lz4==4.4.5`。导入不执行任何文件操作。
- 单元测试命令：`python -m unittest discover -s tests -p test_texture.py -v`，13项通过，包括截断、损坏LZ4、双层非法尾部、尺寸/容量边界、SHA绑定、不透明头字段、精确无修改回写及确定性修改重建。
- 319项实测均解析成功、无修改回写与原成员逐字节一致、RGBA与现有解码PNG一致；每项最后一个像素反色重建后再解码与期望RGBA完全一致。原输入对象保留未变。
- 实测字面结果：`TEXTURE CORPUS PASS decoded=319 noop=byte-identical modified=rgba-identical source=read-only`，退出码0。
- 像素恢复与二进制恢复是不同层面：重新编码原像素只证明像素恢复；精确恢复原容器应使用项目资源差分/原字节，不宣称重压缩等于原压缩字节。

### 可读英文清单的重点

- `GENERAL/EN/LEGEND_*`：16项，Back/Confirm/Equip/Press分别译返回/确定/装备/按下；Esc、SPC、ABXY、圈叉及亚洲键位变体保留。
- `OPTIONS/EN/CONTROLS_*`：11项键盘/手柄说明图，逐图翻译可见标签但不改变实际绑定和连线。库存提供通用标签对应词表，不把该词表冒充每图逐字转录或像素坐标。
- `OPTIONS/EN/LEGEND_*_YAXIS`：4项，Y Axis译纵轴，保留原按钮图标。
- `HUD/THATWASYOURLASTBREATH{,2}`：2项死亡画面，译“这是你的 / 最后一口气”。
- `MOVIES/CHAPTER01..16`及`INTRO`、`AMANDA01`：18项，均有烧录章节标题；INTRO实际显示第一章，AMANDA01显示第三章，不能按文件名另猜剧情。
- `MAP/BG`：标题清晰为Redmoor Hospital，译雷德穆尔医院，复用病房2同地名。
- `TITLE/BG1..4`为四帧品牌与版权背景，不将保留logo说成已替换中文标题。

### 不猜不可辨原文

`EXAMINE008/009/046`的原图仅64像素高，书页与图纸字迹不可可靠逐字辨认。关联examine/item文字的译文可供查看，但不能冒充已逐字覆盖图上笔迹。`ITEMS/ITEMS`含这些物品的更小图标，同样不猜写微字。钢琴上沿装饰铭文未作可靠转写，按谜题组件保留，不擅自更换铭文。
