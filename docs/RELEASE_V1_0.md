# v1.0 简体中文汉化

## 下载与适用版本

在 [GitHub Releases](https://github.com/jyh9521/Dementium-The-Ward-CN/releases) 的 v1.0 附件中下载 `Dementium-The-Ward-zh-CN-v1.0-Setup.exe`。EXE 已上传；附件在 Release 公开发布后对玩家可见。源码 ZIP/TAR 不是可安装补丁。

- 游戏：Dementium: The Ward（《病房》），Steam Windows x64。
- 受支持原版：AppID 3909960 / build21501403。安装器验证原版与改件完整身份，不覆盖未知版本。
- 安装器：78,497,853 字节，产品版本 1.0，PE 版本 1.0.0.0。
- SHA-256：`5bd98a3d21403bada448ef154fcda22914f12b98cb9294b802d8d4aa5c505939`。

## 汉化内容

- 菜单、物品、交互说明、文档及可确认的界面/场景文字。
- 中文字体、电影对白字幕、画面译注与章节标题；保留原视频与音轨。
- 独立 F1 调试菜单与中文调试文本，保留原手柄秘密序列启用后的 L3+Y。
- 最新四处修正：第十五章副标题“初次相遇”；白底绿色“出口”牌；红色手写“有胆你就来！”；汽水机“汽水／泡泡”。

## 安装、升级与恢复

1. 退出游戏，备份重要存档。
2. 运行 EXE，自动检测或浏览选择游戏目录中的 `rom.zar`。
3. 点击“检查资源”，通过校验后点击“安装汉化”。无需 Python 或单独安装 .NET。
4. 恢复时使用同一安装器，检查资源后点击“恢复原版”。不要删除或混用 `cn-backup`。

安装器不启动游戏，不修改存档/设置。若装有早期同名 v1.0 候选或其他模组，先用对应旧安装器恢复原版，再运行本版；不直接覆盖未知改件。详细流程见 [安装说明](INSTALLER.md)。

## 验证与已知边界

发布安装器身份与上传附件的 GitHub SHA-256 一致。既有四处修正记录报告了重复构建、隔离副本安装/恢复、271 项 Python 测试及 59 项 C# 测试；本次仅更新文档，没有重建安装器或重新执行游戏验收。

用户约20分钟简测未见明显问题，不等同于完整通关测试。低清不可确认文字、谜题字符及人名/品牌等有意保留；实际 GPU、输入、字幕同步和全流程仍以玩家反馈为准。见 [已知事项](KNOWN_ISSUES.md) 与 [手动测试](MANUAL_TEST.md)。
